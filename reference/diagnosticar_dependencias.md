# Deprecated Spanish alias for `diagnose_dependencies()`

Deprecated Spanish alias for
[`diagnose_dependencies()`](https://sebollin.github.io/bigbang/reference/diagnose_dependencies.md)

## Usage

``` r
diagnosticar_dependencias(paquetes_locales, ruta_instalables, ext = ".tar.gz")
```

## Arguments

- paquetes_locales:

  Character vector of package archive stems.

- ruta_instalables:

  Directory containing the archives.

- ext:

  Archive extension.

## Value

The result of
[`diagnose_dependencies()`](https://sebollin.github.io/bigbang/reference/diagnose_dependencies.md).
