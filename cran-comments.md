## Update

This is a patch update from 0.6.0, published on 2026-10-24. It comes about
three weeks later mainly to shorten the package's check time on CRAN: the
0.6.0 check takes 704 seconds on r-release-macos-x86_64 and 630 seconds on
r-oldrel-macos-x86_64, most of it in the tests.

- **Shorter checks.** Under CRAN settings the tests now run fast unit checks
  and a smoke test of each area. The integration tests, which generate, build
  and install meta-packages in child R processes, are skipped with
  `skip_on_cran()` and still run in the project's CI with `NOT_CRAN=true`. No
  test was removed. For the source of this submission, the tests take 66
  seconds on R-hub's macOS runner, against 336 for 0.6.0, and the whole
  win-builder check takes 223 and 209 seconds (R-devel and R-release), against
  336 and 305.
- **Bug fixes, with no API changes.** `<meta>_deps(plan = TRUE)` warns when
  the installation library cannot be created or written. Archive warnings are
  reported once per call. Installation log excerpts on Windows no longer end
  in a carriage return. Temporary build directories are removed. The error for
  a re-exported symbol whose component is not installed is clearer.
